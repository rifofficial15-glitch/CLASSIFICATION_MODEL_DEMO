# CLASSIFICATION_MODEL_DEMO

OVERVIEW:

THIS PROJECT IS ABOUT IDENTIFYING WHICH CLASSIFICATION MODEL IS SUITABLE FOR PREDICTING CHRONIC KIDNEY DISEASE..

STEP BY STEP PROCECSS:

* LOAD THE DATASET "ChronicKidneyDisease.csv"

* EXPLORED THE DATA & FOUND WHICH COLUMNS ARE IMPORTANT AND WHICH ARE NOT..

* FOUND THE STATISTICAL INFO..

* CLEANED THE DATASET..

* PREPROCESSED THE DATASET TO CONVERT ALL OBJECTS TO EITHER INTEGER OR FLOAT..

* HANDLED MISSING VALUES & OUTLIERS##########

* USED STANDARDIZATION TECHNIQUE TO SCALE THE FEATURES WHICH ARE IN THOUSANDS, LAKHS & MILLIONS.. WHICH IS USEFUL FOR FINDING PATTERNS..

* VISUALIZED THE DATA TO IDENTIFY DATA STRUCTURE..

* IN MODEL TRAINING, DATASET IS SEPARATED FOR TESTING AND TRAINING USING TRAIN_TEST_SPLIT..

* REMOVED THE OUTLIERS USING Z_SCORE

* TRAINED THE MODEL USING 4 REGRESSION MODEL TECHNIQUES..
1.KNEIGHBOUR REGREEION
2.LINEAR REGRESSION
3.DECISION TREE REGRESSION
4.RANDOM FOREST REGRESSION


* THEN TESTED THE MODEL WITH ORIGINAL DATA USING 3 METRICS..
1.MEAN SQUARED ERROR
2.MEAN ABSOULTE ERROR
3.R SQUARED
