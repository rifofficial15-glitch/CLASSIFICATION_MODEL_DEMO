# CLASSIFICATION_MODEL_DEMO

OVERVIEW:

THIS PROJECT IS ABOUT IDENTIFYING WHICH CLASSIFICATION MODEL IS SUITABLE FOR PREDICTING CHRONIC KIDNEY DISEASE..

STEP BY STEP PROCECSS:

* LOAD THE DATASET "ChronicKidneyDisease.csv"

* EXPLORED THE DATA & FOUND WHICH COLUMNS ARE IMPORTANT AND WHICH ARE NOT..

* FOUND THE STATISTICAL INFO..

* CLEANED THE DATASET..

* PREPROCESSED THE DATASET TO CONVERT ALL OBJECTS TO EITHER INTEGER OR FLOAT..

* HANDLED MISSING VALUES & OUTLIERS...

* DONE CLASSIFICATION BALANCE & FEATURE ENCODING...

* VISUALIZED THE DATA TO IDENTIFY DATA STRUCTURE..

* FOUND CORRELATION...

* IN MODEL TRAINING, DATASET IS SEPARATED FOR TESTING AND TRAINING USING TRAIN_TEST_SPLIT..

* TRAINED THE MODEL USING 5 CLASSIFICATION MODEL TECHNIQUES..
1.NAIVE-BAYES CLASSIFIER
2.KNNEIGHBOUR CLASSIFIER
3.RANDOM FOREST CLASSIFIER
4.DECISION TREE CLASSIFIER
5.SVM CLASSIFIER


* THEN EVALUATED THE MODELS ON THE TEST SET USING 5 METRICS..
1.ACCURACY
2.PRECISION
3.RECALL
4.F1_SCORE
5.CONFUSION_MATRIX

DATASET:

NAME :- ChronicKidneyDisease.csv

SIZE :- 400 rows × 26 columns

FEATURES :- 'AGE', 'BLOOD_PRESSURE', 'SPECIFIC_GRAVITY', 'ALBUMIN', 'SUGAR', 'RED_BLOOD_CELLS', 'PUS_CELLS', 'PUS_CELL_CLUMPS', 'BACTERIA', 'BLOOD_GLUCOSE_RANDOM', 'BLOOD_UREA', 'SERUM_CREATININE', 'SODIUM', 'POTASSIUM', 'HAEMOGLOBIN', 'PACKED_CELL_VOLUME', 'WBC_COUNT', 'RBC_COUNT', 'HYPERTENSION', 'DIABETIS_MELLITUS', 'CORONARY_ARTERY_DISEASE', 'APPETITE', 'PEDA_EDEMA', 'ANAEMIA', 'CLASS'


FINAL DECISION:

DECISION TREE CLASSIFIER MODEL SEEMS TO BE THE EFFICIENT MODEL FOR PREDICTING CHRONIC KIDNEY DISEASE..
